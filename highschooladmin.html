Admin Interface

Enter your table data as JSON. The expected format is a JSON array of rows, where each row is an array of cell values.

Example for a schedule table:

[
  ["Week", "Date", "Opponent", "Location"],
  ["Scrimmage 1", "August 8", "East Ridge, West Carter, Harlan", "HOME"],
  ["Scrimmage 2", "August 15", "EKC vs Paris", "HOME"]
]

Example for a roster table:

[
  ["Jersey", "Player", "Position", "Graduation Year"],
  ["34", "Elias Armstrong", "LB/RB", "2026"],
  ["64", "Brody Johnson", "DL/OL", "2026"]
]
